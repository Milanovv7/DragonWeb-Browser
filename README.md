# DragonWeb-Browser

First of all, for DragonWeb to work make sure you're using one of these browsers (other browsers won't work):

• Google Chrome

• Microsoft Edge

• Brave

SOURCE CODE: https://github.com/Milanovv7/DragonWeb-Online-Demo


DragonWeb v2.3 is here.

Here's what's new:

• Glassmorphism expanded

• Smoother animations

• Toggles are redesigned

• Private mode bug fixed




Make sure that your computer meets its OS requirement:

• macOS 10.12 Sierra or later

• Windows 7 64 bit or later (only Edge will work), Windows 10 64 bit or later for full compatibility

• Linux (depends on the distro)

• ChromeOS version 72 or later






Here's how to get it!


• Click on https://chromewebstore.google.com/detail/ignore-x-frame-headers/gleekbfjekiniecknbkamfmkohkpodhe

• Get the etension

• Click on https://milanovv7.github.io/DragonWeb-Online-Demo/

• While on that website, follow these instructions according to the browser you use:

With Google Chrome:
- Click the 3 vertical dots in the top right corner (in the tab bar next to your Google account)
- Click on "Cast, save and share"
- Click on the doenload option.

With Edge:
- Click the 3 horizontal dots in the top right corner (in the tab bar next to the Copilot Chat button)
- Click on "More tools"
- Click on "Apps"
- Install it.

With Brave:
- Click the three horizontal lines in the top right corner (in the tab bar next to the Brave VPN button)
- Click on "Save and share"
- Install the page as an app.

Enjoy your browsing.
